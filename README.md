# QuantLab

**Plataforma de investigación cuantitativa para trading basado en evidencia.**

## Visión

QuantLab transforma ideas de trading en conocimiento basado en datos. Permite construir,
documentar, probar, analizar y mejorar estrategias de inversión utilizando programación,
ciencia de datos, estadística, probabilidad y finanzas cuantitativas.

En lugar de depender de la intuición, cada estrategia se convierte en un conjunto de
reglas medibles, y cada operación en evidencia para responder preguntas como:

- ¿Existe realmente una ventaja estadística en esta estrategia?
- ¿Cuál es el riesgo real?
- ¿Qué condiciones mejoran el rendimiento?
- ¿Qué probabilidad existe de sobrevivir a una mala racha?

## Estructura del proyecto

- `data/` — datos históricos de mercado
- `notebooks/` — investigación y exploración (Jupyter)
- `src/` — código fuente (funciones, motor de backtesting)
- `src/strategies/` — estrategias implementadas como módulos
- `research_log/` — bitácora de investigación (hipótesis → método → resultado)
- `reports/` — reportes y tear sheets generados
- `tests/` — pruebas automatizadas
